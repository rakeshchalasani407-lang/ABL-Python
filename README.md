ABL - Python Questions:

1. Progressive Electricity Billing: Calculate household bills using multiple consumption slabs, fixed charges, surcharges, and rebates, then compare bills across several months and identify unusual increases.

3. Traffic Violation Penalty Calculator: Process multiple violations using vehicle category, offence type, repeat-offence status, and predefined fine rules; calculate the final penalty and identify disqualification conditions.

8. Examination Result and Grace-Mark Validation: Process marks across multiple subjects, apply subject-wise pass criteria and a specified grace-mark policy, and generate final classifications without exceeding maximum marks.
9. Repeated Word and Phrase Detection: Process a paragraph, normalize letter case, count word occurrences using permitted string and list operations, and identify repeated words and their positions.
10.  Railway Fare and Reservation Calculator: Calculate fares for multiple passengers using distance slabs, travel classes, age-based concessions, reservation fees, and specified cancellation penalties.
